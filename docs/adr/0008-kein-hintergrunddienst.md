# Kein Hintergrunddienst

Automatische Fast-Forwards und Updates laufen nur, solange hud geöffnet ist; es gibt keinen Daemon und keinen launchd-Agent. Das hält jede automatische Aktion sichtbar und an eine bewusst gestartete Sitzung gebunden.

## Konsequenzen

- Wer hud tagelang nicht öffnet, bekommt in dieser Zeit keine automatischen Aktualisierungen.
